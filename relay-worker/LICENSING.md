# Лицензирование: запуск и выдача ключей

Сервер лицензий живёт в том же Worker (`echochat-relay`), что и приём донатов. Отдельных платных сервисов не нужно: Durable Objects с SQLite доступны на бесплатном плане Cloudflare.

## Один раз
1. В Cloudflare: Workers → echochat-relay → Settings → Variables and Secrets → добавить секрет `ADMIN_TOKEN` (длинная случайная строка, не короче 16 символов). Он нужен для входа в админку.
2. Запушить в `main`: workflow `Deploy relay` сам задеплоит Worker и создаст базу лицензий (миграция v2).
3. Открыть `<адрес сервера>/admin` (адрес лежит в `assets/relay-url.txt`), ввести `ADMIN_TOKEN`.
4. Скопировать «Публичный ключ подписи» со страницы в `assets/license-pub.txt` (одна строка). Так приложение будет проверять подпись по закреплённому ключу, а не по полученному при первом соединении.
5. Положить свой QR в `assets/pay-qr.png`, а текст, цену и ссылку на связь указать в `assets/purchase.json` (`contactUrl` только `https://`, например ссылка на Telegram).

## Выдача ключа
В админке: тариф (Pro на N дней или Lifetime), число устройств (по умолчанию 2), заметка → «Создать ключ» → отправить ключ покупателю. Срок Pro отсчитывается с момента первой активации. Там же: продлить, отозвать, сбросить устройства, поднять лимит, удалить.

## Защита донатов Каспи на сервере
В `relay-worker/wrangler.toml` есть переменная `ENFORCE_DONATIONS`. При `"0"` сервер отдаёт донаты всем (так работают старые версии приложения, они не присылают лицензию). При `"1"` приложение при каждом опросе присылает подписанный токен лицензии, и сервер отдаёт события только установкам с пробным периодом, Pro или Lifetime. Включайте `"1"`, когда большинство людей обновилось до 2.1.0 и новее: смените значение, запушьте, workflow `Deploy relay` применит.

## Важно
- Секрет `ADMIN_TOKEN` и приватный ключ подписи хранятся только на сервере. В приложении лежит лишь публичный ключ.
- Пока Worker не задеплоен, приложение работает: пробный период считается локально, затем Lite.
