# ЭхоЧат LIVE

Озвучка чата TikTok LIVE живыми нейро-голосами Microsoft (10 голосов: Светлана, Дмитрий и мультиязычные Ава, Эмма, Вивьен, Серафина, Эндрю, Брайан, Реми, Флориан) — бесплатно, без ключей и карты в тёмном современном приложении для Windows.

- Подключение по нику автора, лента чата, счётчики зрителей / лайков / подарков / подписок
- Озвучка сообщений, подарков и новых подписок
- Фильтры: команды, ссылки, повторы, мат, упоминания, эмодзи, только русский
- Скорость, тон и громкость голоса; пауза и «пропустить»
- Нейро-голоса работают через интернет; если синтез не удался, сообщение просто пропускается

## Запуск из исходников

```bash
npm install
npm start
```

## Сборка exe (Windows)

```bash
npm install
npm run dist
```

Готовый портативный файл появится в `dist/EchoChat-LIVE-1.0.0.exe`.

## Сборка на GitHub

Workflow `Build Windows exe` собирает exe при каждом пуше в `main` (вкладка Actions → артефакт `EchoChat-LIVE-exe`).
Релизы с готовыми exe публикуются не здесь, а в публичный репозиторий `jonny-chat-tiktok` (исходники закрыты). Для этого в Settings → Secrets and variables → Actions нужен секрет `PUBLIC_REPO_TOKEN`: токен GitHub (fine-grained) с доступом к `jonny-chat-tiktok` и правом Contents: Read and write.

## Обновление из приложения

Кнопка «Проверить обновления» (слева внизу, значок обновления) смотрит последний релиз в публичном репозитории `jonny-chat-tiktok`. Если версия новее — скачивает exe и заменяет текущий файл, затем перезапускает приложение.
Чтобы выпустить обновление: подними `version` в `package.json` и запушь в `main` — workflow сам соберёт exe и создаст релиз `v<версия>`.

## Виджет чата (v1.5.0)
Вкладка «Виджеты» → скопируй ссылку (по умолчанию `http://127.0.0.1:7878/chat`) и добавь в OBS как «Браузер», в TikTok LIVE Studio — как «Ссылка». Если TikTok не принимает localhost, выбери другой «Формат ссылки»: `127.0.0.1`, `localhost` или IP локальной сети (при выборе IP сервер виджета открывается для устройств в вашей сети).
Чат TikTok и Twitch на прозрачном фоне с лёгкой тенью; настройки: выравнивание (TikTok слева · Twitch справа), иконки платформ, аватарки, подарки, масштаб и высота в %, исчезающие сообщения. Канал Twitch вводится на вкладке «Эфир» (мультистрим): сообщения Twitch читаются анонимно, ключи не нужны.

### Mac: первый запуск
Приложение не подписано сертификатом Apple, поэтому macOS блокирует его после скачивания. Открыть: перетащить в «Программы», затем «Системные настройки → Конфиденциальность и безопасность» → внизу «Всё равно открыть» (на macOS 15 и новее правый клик → «Открыть» уже не помогает). Если сообщение «повреждено» — в Терминале: `xattr -cr "/Applications/EchoChat LIVE.app"`.

## Подпись команды для iPhone (разовый шаг)
iOS не принимает неподписанные команды, а подписать можно только устройством Apple, где выполнен вход в iCloud (в облачной сборке GitHub входа нет). Любой из способов делается один раз, дальше работает у всех пользователей.

**Способ А, есть Mac:** `node tools/make-template.js t.shortcut && shortcuts sign -m anyone -i t.shortcut -o assets/EchoChat-Kaspi.signed.shortcut`, затем закоммитить файл. Шаблон спрашивает адрес при импорте.

**Способ Б, только iPhone:** в «Командах» создать команду «EchoChat Kaspi» из одного действия «Получить содержимое URL» (URL любой, метод POST, тело запроса JSON, поле `text` = «Ввод команды»). В сведениях команды → «Настройка» добавить вопрос для URL. Поделиться → «Скопировать ссылку iCloud» и вставить ссылку в `assets/shortcut-link.txt`. Тогда QR в приложении ведёт на эту ссылку.
